## 3. Bug 清单

> 详细复现步骤、证据与根因见 `Bug条目_2026-09-06.md`，此处为索引摘要。

### BUG-1: 教室列表接口 500——room_type 为 NULL 时 NPE

- **严重程度**: S1｜**状态**: 新建｜**发现方式**: 手动执行+日志定位
- 现象：基础数据「教室」标签整体不可用（"请求失败 (500)"）
- 根因：`MasterDataRepository.item()` 用 `Map.of` 组装教室属性，`room_type` 为 NULL 时 NPE（`MasterDataRepository.java:191`，E2+日志）；库中 RAPI/RHTTP 两行 room_type 为 NULL
- 回归建议：TC-02-03、TC-02-06、TC-06-01

### BUG-2: 概览接口 500（双根因）且工作台横幅与就绪状态矛盾

- **严重程度**: S1｜**状态**: 新建｜**发现方式**: 手动执行+日志定位
- 现象：工作台显示"基础数据暂时无法读取，无法安全开始排课"，但同面板显示"排课条件已就绪"且求解按钮可用；`GET /api/master-data/overview → 500` 稳定复现
- 根因（双）：① BUG-1 的 NPE；② overview 节次 SQL `WHERE (? IS NULL OR t.code=?)` 在无 termCode 时参数类型推断失败（BadSqlGrammar）——**与 visual-test-report.md 中 RuleFactRepository 已修复的同类问题同模式复发**
- 回归建议：TC-06-01、TC-02-01

### BUG-3: PDF 导出所有中文渲染为问号（CJK 字体缺失）

- **严重程度**: S1｜**状态**: 新建｜**发现方式**: 手动执行（双渲染器交叉验证）
- 现象：课表/校验报告 PDF 布局与数据行完整，但所有中文字符为 `?`（标题"????? v25"）；PDF 无嵌入字体（924 字节）
- 根因：`docker-compose.yml` 未配置 `APP_PDF_FONT_PATH/NAME`，容器无 CJK 字体，PDFBox 回退字体无法映射中文（E2+E4）
- 回归建议：TC-08-03、TC-08-04、TC-08-06

### BUG-4: 会话过期后无法到达登录页，用户被困工作台且无提示

- **严重程度**: S2｜**状态**: 新建｜**发现方式**: 手动执行（重启 API 后操作）
- 现象：`auth:expired` 事件正常派发（实测 8 次），但应用最终停留在 /workspace，无可见提示，此后请求全部静默失败
- 根因：401 只派发事件不清除本地认证状态，路由守卫（`router.ts:31`）把"已认证"用户从 /login 弹回 /workspace（E2 代码链）
- 回归建议：TC-01-04
