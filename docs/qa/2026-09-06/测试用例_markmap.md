# class schedule 测试用例

> **测准声明**：本文件以 `/Users/a1234/Documents/class schedule` 分支 `feat/optional-master-data-sheets` @ `6d8eac3` 实际实现为唯一功能基线；README 与 docs/ 降为背景对照（偏离见附录）。代码级证据统一放文件末尾附录，不写进用例正文。

> **功能简介**：独立中小学排课系统——排课员（Planner）维护学期/基础数据/教学计划，导入模板数据，运行自动排课求解，通过版本管理把课表发布给全校查看并导出 Excel/PDF。本轮为全项目回归 + 真实浏览器验收。
>
> **角色**：Planner（排课员）→ 使用全部功能（基础数据、导入、求解、版本发布、导出）；未登录访客 → 仅登录页。

**环境与账号**：

| 项 | 值 |
|----|----|
| 前端入口 | http://localhost:5173 （Vite dev server，须先启动 docker compose 的 postgres/api/worker） |
| 后端 API | http://localhost:8080 （前端 /api 代理至此） |
| Planner 测试账号 | planner / change-this-in-local-env （bootstrap 默认，执行前先登录验证；失败则查 compose 环境变量 APP_AUTH_BOOTSTRAP_*） |
| 浏览器 | ZCode In-app Browser，视口 1280×720 桌面 |
| 测试数据准备 | 见附录「测试数据准备说明」 |

**术语表**：

| 术语 | 中文名 | 说明 |
|------|--------|------|
| 主数据 | 基础数据 | 教师/班级/课程/教室四类基础信息，页面顶部标签切换 |
| 教学需求 | 教学计划条目 | 某班级某课程某教师的每周课时安排，是排课输入 |
| MASTER_DATA v1 | 统一导入模板 | 中文列名的 Excel 模板；教室/资源可用性/特征/活动组为可选 Sheet |
| 预览 VALIDATED | 导入校验通过 | 上传文件后页面显示的校验状态，只有此状态才允许"确认导入" |
| 求解 | 自动排课 | 提交排课任务，由后台计算课表；状态在页面轮转显示 |
| 版本 | 课表版本 | 草稿(DRAFT)/候选(CANDIDATE)/已发布(PUBLISHED)/已归档(ARCHIVED) |
| roomless 占位 | 无教室占位 | 求解结果中尚未分配教室的课次在网格中的显示形态 |
| 差异 | 版本对比 | 两个版本间课次增删改的对照列表 |
