## automation_plan（用户已裁决）

- 用户指令已裁决执行路径：**先常规测试，后浏览器测试**——不另设提案确认检查点。
- 常规测试：沿用现有 `mvn -f backend/pom.xml verify` 与 `npm run test:run`，不新增框架。
- 浏览器测试：沿用先例形态（ZCode In-app Browser 交互式，DOM 快照 + 截图，1280×720 桌面，Planner 账号），**不引入 Playwright 新框架**（README 明确 Playwright 验收尚未建设，超出本轮范围）。
- 不自动化清单：探索性与视觉人工判断项（PDF 中文字形、布局观感）。

## regression_plan

- 回归锚点（每次必跑）：登录 → 主数据/教学计划/规则事实/版本/已发布五页加载 → 已发布页渲染与导出按钮可见。
- 扩展规则：导入相关变更 → 导入全流程用例全量；主数据变更 → 启停恢复用例；PDF/导出变更 → 导出视觉验收；安全配置变更 → 401/403 冒烟。
