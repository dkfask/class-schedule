# 需求模型 — 2026-09-09

## 1. 测试对象

- **产品**：智程校务智能排课（单校、单学期的排课交付工作台）。
- **目标依据**：[产品设计需求](../../product-design-requirements.md) 的 PD-P0-01 至 PD-P0-08、PD-P1-01 至 PD-P1-06。
- **源码身份**：HEAD `6a0b136`；工作区存在用户已有未提交改动，本轮只在其上做测试相关补充和复盘页面竞态修复。
- **测试时间**：2026-09-09，Asia/Shanghai。

## 2. 角色与边界

| 角色 | 可验证行为 | 本轮验证 |
|---|---|---|
| 排课员 Planner | 导入、配置规则、求解、调整、版本发布、复盘、问题闭环 | 是 |
| 审核员 Reviewer | 查看总览、候选版本、差异、发布检查 | 路由/权限代码与集成测试；未做独立浏览器账号切换 |
| 业务负责人 | 查看交付结果和复盘信息 | 角色代码与接口测试；当前没有独立审批状态机 |
| 只读用户 | 查看已发布课表 | 由既有权限测试覆盖 |

## 3. 核心业务闭环

```text
选择学期 → 准备主数据 → 导入并预检 → 配置教学计划/规则
→ 提交求解 → 检查候选版本 → 调整与锁定 → 发布
→ 查询/导出已发布课表 → 审计、通知、问题反馈、复盘
```

## 5. 关键状态

- 导入：未选择 → 预检中 → 已验证 / 有问题 → 已导入。
- 版本：草稿 / 求解中 / 候选 / 已发布 / 已归档；发布必须经过检查和确认。
- 通知：待处理 → 已读 / 已完成；动作结果必须能回到上下文。
- 问题：新建 → 处理中 → 已解决 / 已关闭；关闭必须有解决结论或证据。
- 学期复用：填写目标 → 复制预览 → 确认复制 → 目标学期重新检查。

## 6. 本轮明确不纳入

独立业务负责人审批状态机、规则重复/覆盖自动检测、移动端、教务系统集成、多校组织/租户、商业化能力、正式生产发布和真实学校 UAT。它们是设计文档列明的待确认或后续范围，不在本轮冒充已验证能力。
