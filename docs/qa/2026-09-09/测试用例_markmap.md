# 测试用例 — 2026-09-09

## P0 主链

- **登录与入口**
  - `TC-P0-01` Planner 登录后进入 `/overview`，总览显示当前学期和下一步动作。
- **导入与准备**
  - `TC-P0-02` 下载导入模板。
  - `TC-P0-03` 合法模板预检通过并确认导入。
  - `TC-P0-04` 仅必需 Sheet 导入不删除已有教室。
  - `TC-P0-05` 非模板文件显示可诊断问题。
  - `TC-P0-06` 重复导入按编码幂等。
- **求解与交付**
  - `TC-P0-07` 工作台显示状态、评分和提示面板。
  - `TC-P0-08` 三种课表视图切换。
  - `TC-P0-09` 提交求解并等待候选结果。
  - `TC-P0-10` 候选结果显示智能诊断面板。
  - `TC-P0-11` 版本列表、差异、锁定/解锁和命令历史可用。
  - `TC-P0-12` 已发布课表只读查询和 Excel/PDF/校验报告下载。

## P1 协作闭环

- `TC-P1-01` 总览、通知、审计、问题、规则模板、复盘、学期复用页面均可加载当前学期数据。
- `TC-P1-02` 问题记录创建后补充解决结论并转为 `RESOLVED`。
- `TC-P1-03` 学期复用先生成预览，清楚区分将复制和不会复制的内容。
- `TC-P1-04` 复盘学校反馈保存成功，刷新后仍读回原值，并恢复测试前数据。
- `TC-P1-05` 通知待办展示上下文并支持完成动作。
- `TC-P1-06` 规则模板保存、预览和应用门禁。

## 专项回归

- `TC-R-01` 复盘首次加载不重复读取当前学期，旧异步响应不能覆盖当前状态。
- `TC-R-02` 旧登录后默认工作台断言调整为设计规定的总览入口。
- `TC-R-03` 问题创建使用 HTTP 201 契约，编辑使用 HTTP 200 契约。
