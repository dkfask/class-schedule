## 8. AI API Key 加密故障复验

- **现象**：系统设置保存 AI API Key 时提示“无法加密 AI API Key，请检查 APP_AI_CONFIG_ENCRYPTION_KEY”。
- **根因（Verified，E3）**：运行中的 `class-schedule-api` 容器未注入 `APP_AI_CONFIG_ENCRYPTION_KEY`；本地 `.env` 中该配置项原先为空/不存在。应用在 AES-GCM 加密前检查到空值并返回该提示。
- **影响范围**：只影响系统管理员保存或更新 AI API Key；已有普通排课、AI 页面访问和其他业务流程不受该配置缺失影响。
- **安全评估**：未发现 API Key 明文回显或日志泄露；修复使用 BCrypt 之外的独立 AES-GCM 配置密钥，密钥值不写入 Git、不写入测试报告。
- **修复**：为本地 `.env` 生成稳定的 256-bit 随机密钥，重建 API/worker 容器；Compose 已将该变量传入应用，后续重启保持一致。
- **复验**：容器内密钥长度为 64 个十六进制字符；API health `200 UP`；使用 `admin` 账号进入 `/settings/ai` 成功，页面错误提示计数为 0。
- **残留项**：生产/预发布环境必须配置独立且持久化的 `APP_AI_CONFIG_ENCRYPTION_KEY`；更换该密钥前需考虑已有密文的迁移，否则历史 API Key 将无法解密。
